Push code to github

git add .
git status
git commit -m "add message here"
git push origin main (to push code to github repo)
git init - used to create new git repo (add .git file to any repo)
git remote add origin
git remote -v (to verify remote)

Branch Commands

git branch (to check branch) git branch - m Main(to change branch)
git push -u origin main (if u will write this once then to push code you have to just write git push) here -u means setting upstream once
git checkout (to navigate)
git checkout -b(to create new branch)
git checkout -d (to delete branch)
